# Vocal Delivery Guide — Day 1 Scripts

Faceless format: voice carries 100% of personality. This guide marks up all 3 scripts.

## Notation

- `/` short pause (~0.3s) — `//` full pause (~0.7s, deliberate dead air)
- **bold** = punch the word (louder, harder consonants)
- *italic* = lean in (quieter, slower — intimacy, not volume)
- `→` speed UP through phrase
- `←` slow DOWN, let each word land
- `↑` energy/pitch rises — `↓` drop low (drops read as confidence)

## Core rules

1. **Stress numbers, not adjectives.** Punch **602**, never "faster". The number is the star.
2. **Pause BEFORE the payoff, never after.** Silence before "it beat C++" = tension. Silence after = dead momentum; cut instantly.
3. **Drop volume for the biggest claim.** Quiet "it beat C++" > shouted. Shouting = hype. Quiet = fact. Want fact energy.
4. **Speed is default, slow is spotlight.** Baseline ~10% faster than natural speech. Slow down only 2-3 moments per video — those become the spotlight.
5. **Only punch 1-2 syllable words.** "Own", "mine", "C++", "five" — punchable. "Programming language" — never; punch the short word before it and let the long one coast.
6. **Smile on the catchphrase.** Audible even faceless. "Mentlegen" = deadpan-formal, butler about to commit crimes.

## Script 1 — full markup

> *Well hello ladies and mentlegen.* `↓ deadpan, formal, slow — joke is HOW polite it is`
>
> // `beat of silence — whiplash setup`
>
> → I built my **own** / programming language. `punch "own" (1 syllable, punchable) — then "programming language" falls out fast, unstressed. Never punch 5-syllable words.` And it's ← **six hundred times** faster than Python. `round number spoken slow; screen shows exact 602x — voice understates, screen proves more`
>
> `Easier alt: "Python was too slow. // So I built my **own**." — noun never spoken, screen says it for you.`
>
> → Same loop. / One **billion** iterations. / Python: one and a half **seconds**. // Mine: two **f*cking** / milliseconds. `punch the swear, "milliseconds" coasts after. Record raw, BLEEP in edit — censor beep is its own joke + dodges shorts suppression. Screen shows exact 2.53ms.`
>
> → Fifteen thousand lines of code. A bytecode VM. A JIT compiler. **Built from scratch.** `machine-gun list, rising ↑, hard stop on "scratch". "Code" not "C++" — first spoken "C++" saved for the payoff line next.`
>
> And on this benchmark — // **YES** — / it beat **C++**. / *Actual.* / *C++.* `"YES" punched short and rising, almost laughing — answers viewer's disbelief before they feel it. Then drop ↓ quiet for "it beat C++". Tail stays dead slow, quiet — THE volume-drop moment`
>
> → I didn't believe it either. So I ran it **five** times. Verified against Python. // *Same answer.* `↓ flat, final — courtroom energy`
>
> **Follow** — because next video, / I show you **how**. `↑ energy up, "how" punched, cut immediately — no fade`

## Script 2 — key moments

- Open cold, no catchphrase energy yet: "My homemade programming language just beat **C++** / and *I can't fully explain it*." — first half confident, second half genuinely puzzled. Honesty in tone IS the hook.
- "Ladies and mentlegen — // **receipts**." — one-word punch. Longest pause in the video before "receipts".
- "**Every.** / **Single.** / **Run.**" — three full stops, equal weight, metronome pacing. Do not rush.
- "→ Before you type the angry comment —" — speed up, playful, intercepting them mid-keystroke.
- "*In a language I wrote in my bedroom.*" — ↓ quiet, almost thrown away. Underselling = flex.

## Script 3 — key moments

- "Here's the whole thing in **fifty seconds**." → then IMMEDIATELY fast. Prove the promise with pace.
- Steps 1-3: same melody each time — "Step **one**: / parser." Repetition is a beat pattern; viewer feels structure.
- "This is where the **speed** lives." — ← slow for one sentence only. Thesis of the whole series.
- "→ String interning. Hash table rewrites. *Each commit* / a little **faster**." — list fast, land soft.
- Final "**six hundred times** faster" — biggest delivery of the video, full stop before it.

## Recording technique

- **Stand up.** Diaphragm opens, energy +20% free.
- **Hands move while talking** even off-camera — changes the voice.
- **Record each paragraph 3x**, splice best takes. Nobody does shorts in one take.
- **First take always stiff.** Read once stupid-exaggerated as warmup, THEN record. Real takes land between stiff and stupid.
- **Mic 10-15cm, slightly off-axis** — kills plosives on "Python", "point", "part".
- Too fast fixes in edit (tighten pauses). Too flat cannot be fixed. Err toward over-delivery.
